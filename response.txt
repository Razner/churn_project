# Etape 1 QUESTIONS : 

1. Pourquoi séparer les fichiers ?
Pour organiser le code et le rendre plus facile à comprendre.
Chaque fichier a un rôle précis (charger les données, entraîner le modèle, etc.), donc c’est plus propre et plus facile à modifier.

2. Pourquoi sauvegarder le modèle ?
Pour éviter de le réentraîner à chaque fois.
Une fois entraîné, on peut le réutiliser directement.

3. Que se passe-t-il si les données changent ?
Le modèle peut devenir moins performant, car il a appris sur d’anciennes données.
Il faut donc le réentraîner avec les nouvelles données pour qu’il reste fiable.

# Etape 2 QUESTION : 

## Partie 1 :

1. Définir une API
Une API est un moyen de communication entre deux applications.
Elle permet à un programme d’envoyer une requête à un autre pour récupérer ou envoyer des données.

2. Différence GET / POST
GET sert à récupérer des données.
POST sert à envoyer des données.

3. Pourquoi utiliser une API en ML ?
Pour pouvoir utiliser le modèle facilement depuis une autre application.
Ça évite de devoir relancer le code à chaque fois.  

## Partie 2 :

1. Qu’est-ce qu’un endpoint ?
C'est une URL de l’API qui permet d’accéder à une fonction précise, comme faire une prédiction.

2. Pourquoi utiliser POST ?
POST sert à envoyer des données à l’API pour obtenir un résultat.

3. Que fait Pydantic ?
Pydantic vérifie que les données envoyées à l’API sont correctes.
